# Common Data Errors (Các lỗi sai dữ liệu thường gặp)

## Sai kí tự

- I -> l
- 0 -> O
- O -> 0
- Q -> O
- 9 -> 0
- 0 ->
- - B -> R
- - t -> I
- - w -> u (Belvieu -> Belview)

## Các lỗi sai về trường dữ liệu

- Sai trường Date khi file có nhiều date
- Sai trường dữ liệu Tax type (GST):
  - 0% -> null
  - null -> 0% hoặc mốt số giá trị
  - Lấy sai Supplier
  - text không có trong PDF
  - Sai Type của tài liệu (Invoice -> Credit note)
  - Sai tên Customer
